  • COMP — Complete  ·  IP — In Progress  ·  WFP — Waiting for Parts
  • TP — mark with * once the time is entered in Tigerpaw. Space bar, click or tap toggles it.
  • Times run in 15 minute steps (0.25). Start fills in from the row above, so you only enter End times.
  • Setting a Start by hand pins that row — it stops following the row above, and shows a red edge. To unpin it, clear the Start: press Delete, or pick the blank entry at the top of the list.
  • Lunch, Off, and any row with no Task chosen don't count toward the daily total.
  • Getting around: arrow keys move between cells and Enter moves down, as in Excel. Tab moves right. Alt+←/→ changes day.
  • Editing: arriving at a cell selects it, so typing replaces what's there. Press F2 (or End) to put the cursor in the text and edit it instead. In a dropdown, type the first letter or press Alt+↓ to open the list.
  • Escape puts the row back to how it was when you moved into it. Ctrl+Z undoes across the whole day, Ctrl+Y redoes — or use the Undo and Redo buttons. Clearing a day can be undone too.
